# calculator
# 經緯儀／全站儀檢校計算工具

本工具用於經緯儀、全站儀之基本檢校資料整理與計算，包含：

- 照準軸誤差 `C`
- 橫軸誤差 `i`
- 垂直指標誤差 `I`
- 一測回水平角精度 `H`
- 儀器精度門檻判定
- CSV 匯入
- 依第 1 測回資料生成第 2、3 測回模擬資料

> 注意：本工具產生之資料主要用於測試、練習、格式檢查與計算流程驗證。正式檢校資料仍應以現場實測紀錄為準。

---

## 功能特色

### 1. 三測回資料輸入

支援輸入三個測回，每測回包含三個目標點：

| 點位 | 說明 |
|---|---|
| 高點 | 高仰角目標 |
| 平點 | 接近水平目標 |
| 參點 | 參考目標 |

每個點位可輸入：

| 類型 | 欄位 |
|---|---|
| 水平角正鏡 | 度、分、秒 |
| 水平角倒鏡 | 度、分、秒 |
| 天頂距正鏡 | 度、分、秒 |
| 天頂距倒鏡 | 度、分、秒 |
